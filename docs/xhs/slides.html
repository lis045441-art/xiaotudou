第 1 轮

让角色站上桌面

用 Electron 在当前文件夹做一个桌宠程序，先只做最基础的部分：

1. 一个透明、无边框、始终置顶、不在任务栏/Dock 显示的小窗口，里面显示 assets/pet.png。
2. 窗口贴在屏幕底部（用 screen.getPrimaryDisplay().workArea，不要压住 Dock/任务栏）。
3. 角色在屏幕底部左右来回走，走到边缘掉头；往左走时图片水平镜像。偶尔停下站一会儿再走。
4. 窗口透明的地方鼠标要能点穿到下面的软件：默认 setIgnoreMouseEvents(true, { forward: true })，鼠标移到角色不透明的像素上时才改成 false（在页面里用 canvas 取像素 alpha 判断）。
5. 主进程和页面之间用 preload.js + contextBridge 通信，不要开 nodeIntegration。
6. package.json 里加 "start": "electron ."。

做完告诉我怎么运行。
    验收
  • npm install → npm start，角色在屏幕底部走
  • 点角色旁边透明处，能点到后面的窗口（最容易出问题）
  • 切到别的软件，角色还在最上面
第 2 轮

能拖、能点、能右键

给桌宠加交互：

1. 按住角色可以拖动，松手后角色从当前位置掉回屏幕底部（简单的重力下落动画）。
   拖动的位置计算放在主进程，用 screen.getCursorScreenPoint()，不要用页面里的 mouse 坐标算窗口位置。
2. 单击（按下到松开移动不到 4 像素）算点击，不算拖动。点击先打印一行日志，下一轮接面板。
3. 右键角色弹出原生菜单：安静模式（不走动，勾选项）、退出。
4. 只允许运行一个实例（app.requestSingleInstanceLock）。
    验收
  • 拖得动，松手会掉回地面
  • 点一下不会误触发拖动
  • 右键菜单能退出
  • 再双击启动一次，不会出现两只
第 3 轮

一张图也能动起来

把角色显示改成 canvas 绘制，支持这几个动作状态：idle（待机）、walk（走路）、sleep（睡觉）、remind（提醒）、drag（被拎起）。
目前只有一张 pet.png，用变换模拟动作：
- idle：轻微上下呼吸（纵向缩放 ±2.5%，横向反向补偿）
- walk：一颠一颠 + 左右轻微摇摆
- sleep：歪头、慢呼吸，头顶飘 z
- remind：原地蹦跳 + 快速抖动
- drag：以头顶为支点左右摆
缩放和摇摆以脚底中心为支点，脚不离地。

再加"电脑闲置 5 分钟就睡觉，一动就醒"：主进程用 powerMonitor.getSystemIdleTime() 判断。

想更自然？升级序列帧

支持序列帧素材：assets/ 下如果有 idle/、walk/、sleep/、remind/、drag/ 子目录，就按文件名数字顺序逐帧播放，优先于单图。缺哪个动作就用 idle 代替。
    素材小建议
  • 所有帧朝同一个方向画，程序会自动镜像
  • 每个动作 2–8 帧就够
  • 图片底边贴着脚底，不然会悬空
第 3 轮 · 进阶

加道具，一张图也能很生动

提醒举牌
拎起挂环
走路速度线
睡觉闭眼
单图模式再加两样，都由 assets/pet.json 控制（没有这个文件就都不开）：

1. 道具层（pet.json 里 "props": true 才画）：
   - remind：角色身侧举一块黄色「!」牌，牌子跟着身体一起蹦跳
   - drag：头顶画一段竖直虚线 + 一个小挂环，挂环不动，身体照常以头顶为支点摆
   - walk：身后画 2–3 道速度线，往哪边走就画在另一边
   开了道具时角色画小一点（约画布的 62%），给头顶的牌子和挂环留位置，牌子不能超出画布。
2. 按动作换图：pet.json 里写 "images": { "sleep": "sleep.png" }，该动作就换这张图，呼吸、歪头、蹦跳这些程序动画照常；没写的动作继续用 pet.png。
    闭眼图怎么画
  • 照着 pet.png 再画一张闭眼的 sleep.png
  • 画布尺寸、角色位置和大小完全一样，只改眼睛和嘴
  • 不然切换动作时角色会跳一下、忽大忽小
第 4 轮 · 选做

便利贴 + 喝水打卡

📝 便利贴 + 到点提醒

单击桌宠时，在角色正上方弹出一个便利贴面板（另一个透明无边框置顶窗口，不要超出屏幕边缘）：
- 可以新增、编辑、删除便利贴，自动保存到 userData 下的 notes.json
- 每条可以设提醒时间；到点后桌宠切到 remind 动作，头顶出气泡显示内容，气泡上有"知道了"和"10 分钟后"两个按钮，同时发一条系统通知（Notification）
- 按 Esc 或点面板外面收起面板
- 关掉面板时空白的便利贴自动清掉

🥤 喝水 / 起身打卡

加一个"打卡"功能，项目从 checkins.json 读（喝水、站起来、走动，每项可配每日目标次数和提醒间隔分钟数）：
- 面板里加一个"打卡"标签页，点按钮打卡，显示今天次数、目标进度、最近 7 天表格
- 打卡后桌宠头顶冒 +1，4 秒内可撤销
- 定时提醒只计用户在用电脑的时间（闲置超过 5 分钟暂停计时），只在 9:00–21:00 提醒
- 记录存在 userData，保留最近 60 天

每个功能单独一轮，做完一个验收一个，别一次全丢给 AI。

第 5 步

打包送给朋友 🎁

用 electron-builder 配置打包：
- Mac：dmg，Apple 芯片（arm64）
- Windows：nsis 安装包 + portable 免安装版，x64
- 图标用 build/icon.png（1024×1024）
- 打包后用固定的数据目录名（app.setPath('userData', ...)），不要随 productName 变
- 右键菜单加"开机自动启动"（app.setLoginItemSettings），只在打包后的版本显示
加上 npm run dist（Mac）和 npm run dist:win。
    朋友第一次打开
  • Mac 提示「无法验证开发者」：右键 App →「打开」
  • Windows 弹蓝框：点「更多信息 → 仍要运行」
  • Mac 安装包要在 Mac 上打，Windows 版最好在 Windows 上打
