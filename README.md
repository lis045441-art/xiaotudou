# 小土豆

桌宠 + 便利贴。一只小土豆在屏幕底部走来走去的小桌宠，点它打开便利贴，到点会举牌提醒。Electron 实现，Mac / Windows 都能用。

## 下载

到 [Releases](https://github.com/lis045441-art/xiaotudou/releases) 下载：

- Mac（Apple 芯片）：`xiaotudou-<版本>-mac.dmg`，打开后把「小土豆」拖进「应用程序」。第一次打开提示「无法验证开发者」时，右键 App →「打开」，或去「系统设置 → 隐私与安全性」点「仍要打开」。
- Windows：`xiaotudou-setup-<版本>.exe`（安装版）或 `xiaotudou-portable-<版本>.exe`（双击即用）。弹出 SmartScreen 蓝框时点「更多信息 → 仍要运行」。

## 从源码运行

```bash
npm install
npm start
```

## 操作

| 操作 | 效果 |
|---|---|
| 左键单击桌宠 | 打开 / 收起便利贴面板 |
| 按住拖动桌宠 | 拎起来，松手后掉回屏幕底部 |
| 右键桌宠 | 菜单：新建便利贴、切换角色、安静模式（不走动）、退出 |
| 面板里 Esc，或点面板以外的任意地方 | 收起面板（正在选提醒时间时不会收起） |
| 提醒气泡「知道了」 | 关掉这条提醒 |
| 提醒气泡「10 分钟后」 | 推迟 10 分钟再提醒 |

- 电脑 5 分钟没有键鼠操作，桌宠会睡觉；你一动它就醒。
- 到点提醒时，桌宠头顶会出现气泡，同时发一条系统通知。
- 关掉面板时没写内容的空便利贴，下次打开面板时自动清掉。

便利贴和设置（当前角色、安静模式）存在本机：

- macOS：`~/Library/Application Support/tudou-pet/` 下的 `notes.json`、`settings.json`
- Windows：`%APPDATA%\tudou-pet\` 下同名文件

## 摸鱼打卡

- **打卡**：面板顶部切到「摸鱼打卡」点按钮，或右键桌宠 →「摸鱼打卡」。打卡后桌宠头顶冒「+1」，4 秒内可撤销。
- **统计**：打卡页显示今天次数、目标进度，以及最近 7 天的表格（颜色越深次数越多）。
- **定时提醒**：喝水 45 分钟、站起来 60 分钟、走动 90 分钟。只计你在用电脑的时间（闲置超过 5 分钟暂停），只在 9:00–21:00 提醒；气泡上点「打卡」或「稍后」（10 分钟后再提醒）。右键 →「摸鱼打卡」里可以关掉。

项目、图标、每日目标、提醒间隔都在 `checkins.json` 里改，重启生效：

| 字段 | 说明 |
|---|---|
| `name` / `short` | 名字；`short` 是按钮和表格里用的短名，可不填 |
| `icon` | 图标名，可选：`kettle` 茶壶、`cup` 水杯、`roll` 卷纸、`toilet` 马桶、`steps` 脚印、`stretch` 伸懒腰、`chat` 对话气泡、`parcel` 纸箱、`onigiri` 饭团。图标画在 `icons.js` 里，颜色跟随角色配色 |
| `goal` | 每日目标次数，不填就只计数 |
| `remindEvery` | 提醒间隔（分钟），不填就不提醒 |
| `remindText` | 提醒气泡的文字 |
| `remindHours` | 允许提醒的时段，默认 `[9, 21]` |

打卡记录存在 `tudou-pet/checkins.json`（和便利贴同一目录），保留最近 60 天。

## 角色

每个角色一个文件夹，放在 `assets/pets/` 下，文件夹名就是角色 ID：

```
assets/pets/
├── tudou/         # 小土豆
│   ├── pet.json
│   ├── pet.png
│   └── sleep.png   # 睡觉时的闭眼图
└── tudou-rain/    # 雨衣小土豆
```

右键桌宠 →「切换角色」即时切换，选择会被记住。新增角色：建一个新文件夹，放素材和 `pet.json`（`name` 字段是菜单里显示的名字），重启生效。


### 下雨自动换装

每 15 分钟（以及电脑睡眠唤醒后）查一次当前天气，天气来自免费的 [Open-Meteo](https://open-meteo.com/)，不用注册。

- 开始下雨（毛毛雨、雨、阵雨、雷雨）：从 `pet.json` 里写了 `"weather": ["rain"]` 的角色中随机挑一个显示。当前是雨衣小土豆。
- 雨停：换回你自己选的角色。
- 下雨期间手动换了角色：以你的选择为准，不会被换回去。
- 右键菜单能看到当前城市、天气和最后查询时间，也可以关掉这个功能。

城市默认是广州。要改的话，编辑 `settings.json` 里的 `"city"`（中文城市名即可），删掉 `"coords"`，然后重启。发给天气服务的只有城市名和经纬度。

素材有两种做法，不用改代码。

### 方式一：单图模式（最省事）

角色文件夹里只放一张透明背景 PNG：`pet.png`。程序用缩放、摇摆、跳动模拟各个动作：

| 动作 | 效果 |
|---|---|
| 待机 | 轻微呼吸起伏 |
| 走路 | 一颠一颠、左右晃 |
| 睡觉 | 歪头慢呼吸 + 飘 z |
| 提醒 | 原地蹦跳 + 抖动 |
| 被拎起 | 以头顶为支点摆动 |

图片建议边长 300–800px，主体占满画面、四周不要留大片透明空白。用别的文件名的话，在 `pet.json` 里写 `"image": "xxx.png"`。

**Mac 上抠图**：用「预览」打开原图 →（可选）先用矩形框选裁出角色，`⌘K` 裁剪 → 鼠标右键角色 →「拷贝主体」→ 菜单「文件 → 从剪贴板新建」→ 导出为 PNG。主体识别不干净时，可以改用「工具 → 即时 Alpha」手动擦除背景。

### 方式二：序列帧（动作更自然）

把图片放进角色文件夹下对应的动作目录。只要有任意一个动作目录，就优先用序列帧，忽略 `pet.png`：

```
assets/pets/<角色>/
├── pet.json        # 名字、尺寸、帧率等配置
├── idle/           # 待机（必需）
│   ├── 0.png
│   ├── 1.png
│   └── ...
├── walk/           # 走路
├── sleep/          # 睡觉
├── remind/         # 举牌提醒
└── drag/           # 被拎起来 / 下落
```

**素材规格**

- 格式：透明背景 PNG，每个动作一组序列帧，文件名按数字排序（`0.png`、`1.png`…或 `walk_01.png`…都可以）。
- 尺寸：建议正方形。图片会按比例缩放到 `size` 大小，**底边对齐地面**，所以角色脚下不要留透明空白。
- 朝向：所有帧统一朝一个方向画。默认朝右；朝左的话把 `pet.json` 的 `facing` 改成 `"left"`。往反方向走时程序会自动镜像。
- 帧数：每个动作 2–8 帧就够。播放速度由 `pet.json` 的 `fps` 控制。
- 缺哪个动作，就用 `idle` 代替；连 `idle` 都没有时显示内置的占位小团子。

**pet.json 字段**

| 字段 | 默认值 | 说明 |
|---|---|---|
| `name` | 文件夹名 | 「切换角色」菜单里显示的名字 |
| `weather` | `[]` | 写 `["rain"]` 表示下雨时可以自动换成它 |
| `theme` | 黄色默认配色 | 便利贴面板和提醒气泡的配色，4 个颜色：`ink` 描边/文字、`panel` 面板底色、`card` 便利贴卡片、`accent` 按钮。其余深浅色由 `theme.js` 自动推算 |
| `size` | 单图 120 / 序列帧 96 | 角色显示边长（像素） |
| `facing` | `"right"` | 素材里角色朝向 |
| `flip` | `true` | 往素材反方向走时是否镜像；设为 `false` 则永远保持原图朝向 |
| `image` | `"pet.png"` | 单图模式的文件名 |
| `images` | 无 | 单图模式下按动作换图，如 `{"sleep": "sleep.png"}`；没写的动作用 `image`。各张图画布尺寸、角色位置要和 `image` 一致 |
| `props` | `false` | `true` 时单图模式加道具：提醒举「!」牌、被拎起头顶挂环、走路速度线。角色会缩小一些给道具留位置，可调大 `size` 补回 |
| `pixelArt` | 序列帧 `true` / 单图 `false` | `true` 放大时保持像素颗粒，适合像素风；`false` 平滑缩放，适合手绘风 |
| `fps` | 见文件 | 序列帧模式下各动作每秒播放几帧 |

## 打包

```bash
npm run dist       # Mac，产物在 dist/
npm run dist:win   # Windows
```

- 只打 Apple 芯片（arm64）的 Mac 版。Mac 安装包只能在 Mac 上打，Windows 版建议在 Windows 上打。
- 没有 Apple 开发者证书，用的是临时签名（ad-hoc）。
- 打包后的 App 和开发版共用 `tudou-pet` 数据目录，两者不能同时运行。
- 右键菜单里的「开机自动启动」只在打包后的 App 里可用。
- App 图标在 `build/icon.png`（1024×1024），替换后重新打包即可。
